# Scratch Context README

## What this is
A scratch context file is a temporary text file you can use to collect the exact information you want Copilot to see.

It helps you make your prompt more deliberate and easier to review.

## Why use it
Using a scratch context file helps you:
- make the context visible before you send it
- avoid accidentally including too much irrelevant text
- test prompts more systematically
- keep a reusable structure for debugging, summarizing, or fixing code

## When to use it
Use it when you want to:
- debug an issue
- explain a bug or error
- ask for a code review or fix
- summarize a large amount of context
- compare different prompts or versions of context

## How to use it
1. Open the scratch template file.
2. Fill in the goal, instructions, and context sections.
3. Paste the relevant code, logs, or error output.
4. Add any important files or references.
5. Ask Copilot to work from that file or from the assembled context.

## Recommended structure
- Goal: what you want Copilot to do
- Instructions: how you want the answer shaped
- Context: the code, logs, or files to include
- Expected Output: what result you want back

## Tip
Keep the scratch file small and focused. Remove anything that is not necessary for the task.

## Example use cases
- “Summarize this issue and suggest a fix”
- “Explain this error and identify the root cause”
- “Review this code snippet and propose an improvement”
